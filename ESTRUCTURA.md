# Estructura Completa - Casa Virtual de Picóscar

```
picoscar.github.io/
├── _config.yml                 # ⚙️ Configuración principal de Jekyll
├── _layouts/
│   └── default.html            # 🎨 Layout base (header, footer, modal)
├── assets/
│   ├── css/
│   │   └── style.css           # 🎨 Estilos (paleta gris, responsive)
│   └── js/
│       └── main.js             # ⚡ JavaScript (modal, parallax)
├── index.md                    # 🏠 Página de inicio
├── Gemfile                     # 📦 Dependencias Ruby
├── .gitignore                  # 🚫 Archivos a ignorar
├── README.md                   # 📖 Documentación
└── SETUP.md                    # 🚀 Instrucciones de instalación
```

## 📋 Contenido de cada archivo

### 1. **_config.yml**
- Título y descripción del sitio
- URL base
- Configuración de Jekyll
- **Links de redes sociales** (Instagram, Facebook, GitHub, LinkedIn, YouTube, Email)
- Colecciones para proyectos futuros

### 2. **_layouts/default.html**
- HTML base para todas las páginas
- Header con logo `picoscar.com`
- Botón hamburguesa interactivo
- Modal elegante con:
  - **Redes sociales visibles** (con iconos SVG)
  - Opciones del menú (ocultas con CSS)
- Footer con redes y copyright 2026
- Carga de CSS y JS

### 3. **assets/css/style.css**
- Paleta de grises (8 tonos)
- Estilos del header y logo
- Menú hamburguesa + modal
- Redes sociales con hover
- Hero section
- Puerta centrada
- Footer
- Responsive para móvil

### 4. **assets/js/main.js**
- Control del modal (abrir/cerrar)
- Animación hamburguesa (X)
- Parallax con mouse
- Parallax con scroll
- Manejo de eventos

### 5. **index.md**
- Página de inicio
- Contenedor para la puerta
- Imagen placeholder (cambiar después)

### 6. **Gemfile**
- Dependencias Jekyll
- Tema minima
- Plugins

### 7. **.gitignore**
- Archivos a no hacer push

### 8. **README.md**
- Documentación completa
- Instrucciones de instalación local
- Cómo personalizar
- Cómo usar GitHub Pages

### 9. **SETUP.md**
- Instrucciones paso a paso para GitHub
- Configuración de dominio personalizado
- Troubleshooting

## 🚀 Próximos pasos

1. **Descarga los archivos** de `/mnt/user-data/outputs/`
2. **Sigue SETUP.md** para subir a GitHub
3. **Accede** a `https://picoscar.github.io`
4. **Personaliza** la imagen de la puerta
5. **Activa** las secciones del menú cuando quieras
